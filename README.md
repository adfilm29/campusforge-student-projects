# CampusForge — Student Project Lab

A practical portfolio of **50+ student-focused software projects**, built from beginner to advanced level. The goal is to solve real campus problems and demonstrate programming, product thinking, UI design, data handling, and AI integration.

> Built as a learning lab: each project should be runnable, documented, and honest about what is implemented versus planned.

## Project collection

| Track | Focus | Level |
|---|---|---|
| 01 · Student productivity | Study planning, assignments, focus, notes | Beginner–Intermediate |
| 02 · Campus life | Lost & found, events, clubs, transport, canteen | Intermediate |
| 03 · Exams & learning | Quizzes, flashcards, revision, PDF learning tools | Beginner–Advanced |
| 04 · Career & placement | Resume, interview practice, internship tracking | Intermediate–Advanced |
| 05 · Money & wellbeing | Budgets, fees, scholarships, habit tools | Beginner–Intermediate |
| 06 · Developer tools | Code practice, API/JSON/SQL helpers, visualizers | Intermediate |
| 07 · AI & ambitious builds | RAG study assistant, team matching, campus intelligence | Advanced |
| 08 · Java & Python | OOP, algorithms, CLI and backend practice | Beginner–Advanced |

## Getting started

1. Open a project folder.
2. Read its `README.md` for purpose, features, and limitations.
3. For browser projects, open `index.html` directly or use VS Code Live Server.
4. For Python/Java projects, follow the run instructions in that project's README.
5. Never put private API keys or passwords in source code. Use environment variables for backend projects.

## Quality bar

- Working core interaction, not just a mockup.
- Responsive and accessible UI where relevant.
- Clear setup and usage instructions.
- No fake AI claims: projects requiring a model/API must say so.
- Small, meaningful commits and incremental improvements.

## Project roadmap

The catalogue is organized into numbered tracks. Each folder contains independent projects. More advanced projects may have a separate backend, database, or API setup.

## Learning path

**Start:** browser fundamentals → JavaScript logic → local storage → Git/GitHub  
**Next:** Python + data structures → Java + OOP → APIs + databases  
**Then:** authentication, testing, deployment, AI integrations, and system design.

## Contribution

Pick an issue-sized improvement, explain the problem, implement it, test it, and document how to run it. Avoid uploading copied tutorial code without understanding it.
