# CampusForge — Student Project Lab

A practical portfolio of **56 student-focused software projects**, built from beginner to advanced level. The goal is to solve real campus problems and demonstrate programming, product thinking, UI design, data handling, and software fundamentals.

## Run a project

1. Open its folder and launch `index.html` in a modern browser.
2. Or use VS Code Live Server for a local development server.
3. No package installation or build step is required for these browser-first prototypes.

## Important limitations

- Most projects use browser `localStorage`; their data remains on the current browser/device and is not synced to a server.
- These are functional learning prototypes, not production campus systems.
- No live college integrations or external AI model calls are claimed. Tools that generate prompts or questions use transparent templates.
- Do not enter sensitive personal information into prototype apps.

## Learning path

**Start:** HTML/CSS/JavaScript → browser storage → Git/GitHub  
**Next:** Python + data structures → Java + OOP → APIs + databases  
**Then:** authentication, testing, deployment, real AI integrations, and system design.
